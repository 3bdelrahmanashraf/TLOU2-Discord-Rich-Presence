NOTES
-----
- Keys are case-sensitive only in the sense that Discord stores exactly what
  you type. Use the lowercase spelling shown here.
- "The Farm" appears in both campaigns but uses the single `the_farm` key.
- "St Mary's Hospital" is stored as st_marys_hospital (no apostrophe).
- The hover text on the large image is the mission name automatically
  (config: large_text_template = "{subchapter}").
- The helper retries with "tlou2" if a mission key has not been uploaded yet,
  so presence keeps working while you add art gradually.
- No Return never falls back to "tlou2": if "no_return" is missing, that status
  is text-only ("Playing NO RETURN") until the asset is uploaded.
